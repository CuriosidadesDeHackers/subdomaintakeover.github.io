# 🌐 Subdominio Takeover PoC

¡Bienvenido al repositorio de Prueba de Concepto (PoC) para la obtención del subdominio `subdomaintakeover.github.io`! 🚀

## 📝 Descripción

Este repositorio ha sido creado con el propósito de demostrar cómo se puede realizar una toma de control de subdominio (subdomain takeover) en un entorno controlado. La idea es educativa y está diseñada para mostrar cómo funcionan estas vulnerabilidades y cómo pueden ser explotadas.

## 🔗 Artículo Explicativo

Para una explicación detallada sobre cómo se lleva a cabo este proceso, puedes consultar el siguiente artículo:

[Curiosidades de Hackers](https://www.curiosidadesdehackers.com/)

## 🌐 Configuración del Subdominio

El subdominio `http://subdomaintakeover.curiosidadesdehackers.com/` tiene un registro CNAME que apunta a `subdomaintakeover.github.io`. Esto significa que cualquier contenido alojado en este repositorio de GitHub Pages será servido a través de `http://subdomaintakeover.curiosidadesdehackers.com/`.
